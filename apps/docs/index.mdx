Most Gmail integrations fail in production because of duplicate push notifications, missed changes from bad cursor handling, invalid or expired Gmail history cursors, revoked OAuth tokens, and webhook endpoints going down. 

Mailmon solves these issues by treating email sync as a distributed systems problem, providing a robust infrastructure to keep your application in perfect sync with your users' mailboxes.

## What is Mailmon?

Mailmon is a Gmail-first sync API that provides correct mailbox state, durable events, and replayable webhooks. Instead of building your own polling loops and Gmail push listeners, you use Mailmon to handle the complexity of the Gmail API.

## Core Concepts

Understanding these core concepts will help you integrate Mailmon effectively:

- **Mailboxes**: The unit of work in Mailmon. Each mailbox represents a connected Gmail account. Mailmon automatically handles cursor tracking and sync leases behind the scenes.
- **Connect Sessions**: Secure, ephemeral sessions used to authenticate users via Google OAuth and connect their mailboxes to your workspace.
- **Events**: Immutable records of changes (e.g., `message.created`, `thread.updated`) stored in our durable event log.
- **Webhook Endpoints**: Your application's HTTP endpoints that subscribe to Mailmon events.
