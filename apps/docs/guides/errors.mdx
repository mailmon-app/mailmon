When an API request fails, Mailmon returns standard HTTP status codes along with a structured JSON error response.

## Error Response Format

All API errors return a standard JSON shape that includes a top-level `error` object. This object contains an `id`, an `code`, a human-readable `message`, and an HTTP `status`.

```json
{
  "error": {
    "id": "err_...",
    "code": "invalid_request_error",
    "message": "The provided mailboxId is invalid or does not exist.",
    "status": 400
  }
}
```

### Error Codes

The `code` field is a machine-readable string that categorizes the error. Common error codes include:

- `invalid_request_error`: The request was invalid or could not be served.
- `not_found_error`: The requested resource could not be found.
- `rate_limit_error`: You have exceeded the allowed number of API requests.
- `internal_server_error`: An unexpected error occurred on Mailmon's end.

## Handling Errors with the SDK

If you are using the official `@mailmon.dev/sdk`, API errors are thrown as exceptions. You can catch these exceptions to handle errors programmatically.

```typescript
import { MailmonClient, MailmonError } from "@mailmon.dev/sdk";

try {
  const mailbox = await client.getV1Mailboxes({ mailboxId: "mbx_invalid" });
} catch (error) {
  if (error instanceof MailmonError) {
    console.log(error.code); // e.g., "not_found_error"
    console.log(error.status); // e.g., 404
    console.log(error.message); 
  } else {
    // Handle unexpected/network errors
  }
}
```

## Status Codes

| Status Code | Description |
| :--- | :--- |
| `400` | **Bad Request** - The request was unacceptable, often due to missing a required parameter or failing validation. |
| `401` | **Unauthorized** - No valid API key provided. |
| `403` | **Forbidden** - The API key doesn't have permissions to perform the request. |
| `404` | **Not Found** - The requested resource doesn't exist. |
| `409` | **Conflict** - The request conflicts with another request (e.g., trying to create a resource that already exists). |
| `429` | **Too Many Requests** - Too many requests hit the API too quickly. |
| `500, 502, 503, 504` | **Server Errors** - Something went wrong on Mailmon's end. |
