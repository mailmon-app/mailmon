# Mailmon Documentation

This directory contains the [Mintlify](https://mintlify.com) documentation for Mailmon.

## Local Development

Install the [Mintlify CLI](https://www.npmjs.com/package/mint) to preview your documentation changes locally.

```bash
npm i -g mint
```

Run the following command at the root of your documentation (this directory):

```bash
mint dev
```

View your local preview at `http://localhost:3000`.

## Publishing changes

The documentation is automatically deployed via Mintlify's GitHub integration when changes are pushed to the main branch.
