Learn how to connect a user's Gmail account and start receiving webhooks for new messages in minutes.

## 1. Install the SDK

The official Mailmon TypeScript SDK is the easiest way to interact with the API.

<CodeGroup>
```bash npm
npm install @mailmon.dev/sdk
```
```bash pnpm
pnpm add @mailmon.dev/sdk
```
```bash yarn
yarn add @mailmon.dev/sdk
```
</CodeGroup>

## 2. Initialize the Client

Initialize the client with your workspace API key.

```typescript
import { MailmonClient } from "@mailmon.dev/sdk";

const client = new MailmonClient({
  token: process.env.MAILMON_API_KEY,
});
```

## 3. Connect a Mailbox

To start syncing a user's emails, you need to create a connect session. This will provide a URL to redirect the user to for Google OAuth.

```typescript
const session = await client.postV1MailboxesConnectSessions({
  provider: "gmail",
  tenantExternalId: "user_123", // Your internal user ID
  mailboxExternalId: "primary", // An identifier for this mailbox
  redirectUrl: "https://your-app.com/oauth/callback"
});

// Redirect the user to session.connectUrl
console.log(session.connectUrl);
```

After the user completes OAuth, they will be redirected to your `redirectUrl`, and Mailmon will automatically create the mailbox and begin the initial sync.

## 4. Set up Webhooks

To receive real-time updates when new emails arrive, create a webhook endpoint and subscribe it to the events you care about.

```typescript
// 1. Register your endpoint
const endpoint = await client.postV1WebhookEndpoints({
  url: "https://your-app.com/webhooks/mailmon"
});

// 2. Subscribe to events for specific mailboxes
await client.postV1WebhookEndpointsByEndpointIdSubscriptions({
  endpointId: endpoint.id,
  mailboxIds: ["mbx_..."], // The ID of the connected mailbox
  eventTypes: ["message.created"]
});
```

<Warning>
Mailmon guarantees **at-least-once delivery**. Your webhook handler should use the event `id` to deduplicate incoming webhooks.
</Warning>

## 5. Handling Webhooks

When a user receives a new email, Mailmon will send a POST request to your webhook endpoint.

```json
{
  "id": "evt_...",
  "type": "message.created",
  "schemaVersion": 1,
  "occurredAt": "2026-05-04T10:00:00.000Z",
  "workspaceId": "wsp_...",
  "tenantExternalId": "user_123",
  "mailboxId": "mbx_...",
  "data": {
    "messageId": "msg_...",
    "threadId": "thr_...",
    "providerMessageId": "195f8c...",
    "providerThreadId": "195f8b...",
    "subject": "Hello",
    "snippet": "Email snippet...",
    "receivedAt": "2026-05-04T09:59:00.000Z",
    "labelIds": ["INBOX", "UNREAD"]
  }
}
```
